### ② 기본 게임 만들기 (커밋 `2339783`, `697b741`)
- 피아노 롤 보드: 왼쪽 건반, 재생 라인, 음 블럭이 있는 보드가 왼쪽으로 흐름
- 흰·검은 블럭 = 원곡 멜로디(안 깨짐), 컬러 블럭 = 방해 음(깨짐)
- 스테이지 = 노래 한 소절(8박), 스테이지당 30번 발사
- 30번이 끝나면 남은 방해 블럭이 재생 라인에 닿아 틀린 음으로 연주됨
- 별: 남은 방해 블럭 0개 ★★★ / 1~5개 ★★ / 6~10개 ★ / 11개 이상 GAME OVER
- 곡의 모든 스테이지를 깨면 전곡 듣기
- 수록곡 4곡(저작권 만료): 작은 별, 비행기, 징글벨, 환희의 송가 — 총 16스테이지
- 휴대폰 화면 높이에 맞게 늘어나도록 조정

### ③ 발판 · 숫자 블럭 · 아이템 (커밋 `e1ef6f9`)
- 바닥에 **발판**(하얀 건반 모양)이 있고, 공이 날아가는 동안 좌우로 밀어 받아냄. 놓친 공은 사라짐
- 모든 방해 블럭에 **숫자(체력)** 표시, 숫자만큼 맞혀야 깨짐
- 특수 블럭(한 번에 깨짐)
  - ⊕ 공 추가: 그 자리에서 공 하나 더 + 다음 발사부터 공 +1 (최대 5개)
  - ⚡ 속도 UP: 이번 턴 동안 공이 빨라짐
  - ↔ 발판 UP: 아이템이 천천히 떨어지고, 발판으로 받아야 발판이 넓어짐
- 한 턴이 끝나는 조건: 쏜 공을 모두 놓치거나 8초가 지남 (턴이 길어질수록 공이 빨라짐)
- 화면 맨 아래에 지나간 아이템 자국이 남던 버그 수정

### ④ 재생 라인 왼쪽 끝 · 멜로디 충돌음 · 배경음 (커밋 `d1507b3`)
- 재생 라인을 건반 바로 옆(왼쪽 끝)으로 이동, 보드가 나머지 공간을 모두 사용
- 칸을 반 박자 단위로 쪼갬 (스테이지 = 16칸 = 8박), 방해 블럭 수 증가
- 공이 **어떤 블럭에 부딪혀도 곡 멜로디가 한 음씩 이어서** 울림
- 배경: 지금 곡의 코드로 된 잔잔한 반주(패드·낮은 음·오르골)가 4마디씩 반복 + 바람 소리
- 곡 연주 중에는 반주가 작아짐, 앱이 백그라운드로 가면 소리 멈춤
- 소리 크기 실측: 배경 약 -30dB, 블럭 멜로디 약 -15dB, 곡 연주 약 -13dB

### ⑤ 새 곡 만들기 (커밋 `eba6313`)
곡 선택 화면 → **+ 새 곡 만들기**
- **노래 제목으로**: 제목(과 가수)을 적으면 Claude가 대표 구간 멜로디·코드를 받아 적어 맵 생성
  - claude.ai 아티팩트로 열었을 때만 동작 (Claude 사용 허용 필요, 사용량은 내 계정)
  - 같은 제목은 하루 동안 저장된 답을 재사용
- **음악 파일로**
  - MIDI(.mid): 악보 그대로 읽음 (멜로디 트랙 자동 선택) — 가장 정확
  - MP3·WAV·M4A: 브라우저 안에서 템포·박자·멜로디·조성·코드 분석, 시작 시간부터 80초 분석
- 난이도(쉬움/보통/어려움), 길이(최대 4·6·8스테이지) 선택, 반복 구절은 한 스테이지로 합침
- 만든 곡은 **내가 만든 곡**에 저장(이 브라우저), 두 번 눌러 삭제

### ⑥ 화면 비율 · 건반 수 (커밋 `aaa3c82`)
- 참고 화면처럼 **피아노 롤이 화면의 약 70%**, 아래 발판 영역 약 20%
- 위쪽을 한 줄 막대로: 나가기 · 곡 제목/점수 · 남은 방해 블럭(별 미리보기) · 남은 발사 수(원형 링) · 소리 · 다시하기, 그 아래 초록 진행선
- 타임라인에 마디 번호 표시
- 건반 최소 24개(2옥타브)
- 첫 턴 안내를 보드 위 반투명 상자로 이동

### ⑦ 검은 건반 블럭 통과 (커밋 `dd752f0`)
- 멜로디가 빽빽해 길이 막히는 곡이 있어서 **검은 건반 음 블럭은 공이 그냥 지나가게** 변경
- 지나갈 때 빛나며 멜로디 음이 울림, 반투명·점선 테두리로 표시
- 흰 블럭은 그대로 튕김

### ⑧ GitHub 연결 · 푸시

- GitHub 연결 후 커밋 7개를 작업 브랜치에 푸시 완료

### ⑨ 단일 HTML5 파일로 합치기 (커밋 `454227a`, 로컬 Claude Code)
- `style.css`와 `js/` 스크립트 6개를 `index.html` 하나에 넣음 (약 137KB). 이 파일만 복사해도 실행됨
- 코드·규칙·밸런스는 그대로, 원래 파일 자리는 `/* ===== js/이름.js ===== */` 주석으로 표시
- 바깥에서 받는 것은 제목 글꼴(Google Fonts) 하나뿐, 인터넷이 없으면 기본 글꼴로 보임

### ⑩ ElevenLabs 고품질 소리 · 멜로디 악기 10종 · 발판 위치 (로컬 Claude Code)
- 합성음을 **ElevenLabs 효과음 API**(`eleven_text_to_sound_v2`)로 만든 녹음으로 교체: 피아노, 뮤직박스, 패드, 베이스, 틀린 음, 블럭 깨짐, 발사, 발판 노크, 공 놓침, 바람(끊김 없는 반복)
- **멜로디 악기 10종** 선택(곡 선택 화면 위 `악기` 줄, 고르면 미리듣기, 선택은 저장): 피아노 · 뮤직박스 · 하프 · 마림바 · 기타 · 바이올린 · 플루트 · 첼레스타 · 전자피아노 · 비브라폰
- 만드는 방법: 악기·음마다 후보를 2~3개씩 생성(약 170개, ElevenLabs 크레딧 약 1만 5천 사용) → 음높이 분석(librosa pyin) + 스펙트로그램으로 깨끗한 단음만 고름 → 앞 무음 자르기, 음량 맞추기, 모노 MP3(80~96kbps) → base64로 `index.html`에 넣음
- ElevenLabs는 요청한 음높이를 정확히 지키지 않아서(C·G 근처로 몰림) 녹음마다 실제 음높이를 재 두고 재생 속도로 맞춤
- 배경 패드는 녹음이 충분히 길게 유지되도록 한 옥타브 낮춰 연주
- 블럭이 깨질 때 효과음이 멜로디 음과 겹쳐 막히던 것을 고쳐, 이제 깨짐 소리가 함께 들림
- 발판을 아래 영역 맨 아래(바닥 44px 위)에서 **가운데쯤**으로 올림 (`PADDLE_AT: 0.5`) — 폰에서 발판 아래를 잡아도 발판이 보이게
- `index.html` 크기 약 1.6MB (소리 데이터가 대부분)

### ⑪ Codex 노래 찾기 · 추가 발사 · 공 꼬리/블럭 조각/화면 흔들림 (로컬 Claude Code)
- **노래 찾기(Codex)**: 새 곡 만들기 → 노래 찾기에서 아무 노래나 검색 → Codex가 웹 검색으로 후보 최대 6곡 → 고르면 멜로디·코드·템포를 받아 적어 맵 생성
  - 웹 페이지는 Codex 구독을 직접 못 부르므로, 이 PC에서 도는 작은 Node 서버 `codex-bridge.mjs`(실행: `codex-bridge.cmd`)가 `codex exec`를 대신 실행
  - 안전: `127.0.0.1`에서만 열림, 로컬 페이지·파일·GitHub Pages 주소만 허용, 지시문은 브리지 안에 고정(게임은 노래 글자만 보냄), Codex는 읽기 전용 + 웹 검색, 빈 임시 폴더
  - `--output-schema`로 답을 JSON 모양에 맞추고, 찾기는 추론 강도 low, 받아 적기는 medium, 결과는 하루 캐시
  - 실측: 찾기 약 16~18초, 받아 적기 「좋은 날」 약 3.6분(128 BPM, A♭장조, 91음)
- **추가 발사**: 공이 날아가는 중에도 보드를 눌러 조준·떼면 또 발사 (발사 횟수 1 사용, 턴 8초 다시 시작). 키보드 Space도 됨. 아래 영역을 밀면 발판 이동
- **효과**: 날아가는 공에 빛 꼬리, 블럭이 깨지면 3×3 조각과 불티가 흩어짐, 블럭이 0이 되어 깨질 때 작은 화면 흔들림

### ⑫ 실사 건반 · 눌림 (로컬 Claude Code)
- Codex 이미지 도구(imagegen)로 위에서 내려다본 흰 건반·검은 건반(앞쪽 끝이 오른쪽)과 손가락 끝(크로마키 초록 배경)을 생성
- 같은 Codex 세션에서 이미지 편집으로 **눌린 건반**(더 어둡고 옆 건반 그림자) 버전을 만듦
- 건반은 앞쪽 부분만 잘라 WebP로, 손가락은 초록 배경을 지우고 뿌리 쪽을 서서히 투명하게 → `PB.KEY_ART`(약 9KB)로 `index.html`에 넣음
- 음이 울리면 그 건반이 눌린 그림으로 바뀜(맞는 음 금색·틀린 음 빨간빛). 그림을 불러오기 전에는 예전 그림 방식
- 손가락이 건반을 누르는 애니메이션도 넣었다가, 사용자 요청으로 뺌 (손가락 그림도 파일에서 제거)
- 흰 건반은 한 옥타브를 7개가 똑같이 나눠 갖게, 검은 건반은 실제 피아노 배치(도~미 3건반을 5칸, 파~시 4건반을 7칸)로 맞춤

### ⑬ 노래 찾기 「만들기」 버튼 · 플레이 중 악기 바꾸기 (로컬 Claude Code)
- 찾은 곡 카드 오른쪽에 노란 「만들기 ▶」 버튼 표시 (원래도 카드를 누르면 만들어졌지만 버튼처럼 안 보였음)
- 위쪽 바에 ♪ 버튼 추가 → 악기 10종 창. 고르면 미리듣기, 다음 음부터 적용, 곡 선택 화면과 선택 공유
- 창이 열려 있는 동안 조준·발사 중이면 게임을 멈춤(곡 연주 중에는 소리와 어긋나지 않게 안 멈춤). Esc·바깥 누르기·✕로 닫기
- 버튼 자리를 위해 위쪽 바의 별·방해 칸과 남은 발사 링을 왼쪽으로 당김

## 2. 현재 게임 규칙

| 블럭 | 의미 | 공에 맞으면 |
|---|---|---|
| ⬜ 흰 블럭 | 원곡 멜로디 (흰 건반 음) | 안 깨짐, 튕김 |
| ⬛ 검은 블럭 (반투명·점선) | 원곡 멜로디 (검은 건반 음) | 안 깨짐, 그냥 통과 |
| 🟦🟩🟥🟨🟪 컬러 블럭 | 방해 음 | 적힌 숫자만큼 맞히면 깨짐 |
| ⊕ / ⚡ / ↔ 특수 블럭 | 방해 음 + 아이템 | 한 번에 깨지고 아이템 획득 |

- 스테이지당 발사 30번, 발사할 때마다 보드가 재생 라인 쪽으로 흘러감
- 한 턴 = 쏜 공을 모두 놓치거나 8초 경과
- 30번이 끝나면(또는 방해 블럭을 다 깨면) 보드가 재생 라인을 지나가며 연주, 남은 방해 블럭은 틀린 음
- 별: 0개 ★★★ · 1~5개 ★★ · 6~10개 ★ · 11개 이상 GAME OVER
- 한 곡의 모든 스테이지를 깨면 전곡 듣기 (남겨 둔 방해 블럭도 틀린 음으로 연주)

## 3. 조작
- 터치/마우스: 보드를 눌러 조준 → 손을 떼면 발사, 공이 날아가는 동안 좌우로 밀어 발판 이동
- 조준 중 발판 줄을 누르고 밀면 발사 위치(발판)를 옮길 수 있음
- 키보드: ← → 조준 / 발판 이동, Space·Enter 발사

## 4. 밸런스 수치 (`index.html`의 core 부분)

| 항목 | 값 |
|---|---|
| 공 속도 | 620 (턴 중 2초마다 +5%, 최대 1.5배) |
| 발판 너비 | 110 (발판 UP 한 번에 +30, 최대 190) |
| 턴 제한 시간 | 8초 |
| 방해 블럭 수 | 24 + 1.2 × 단계 |
| 블럭 체력 평균 | 1.85 + 0.43 × 단계 |
| 특수 블럭 | 공 추가·속도·발판 각 1개 (6단계부터 공 추가 +1, 11단계부터 발판 +1) |
| 만든 곡 난이도 | 쉬움 0 · 보통 5 · 어려움 10단계에서 시작, 스테이지마다 +1 (최대 +5) |

난이도는 발판으로 공을 받는 확률이 65%·80%·90%인 가상 플레이어 시뮬레이션으로 맞췄습니다.
첫 곡은 누구나 ★★★, 뒤로 갈수록 ★★가 많아지고, 서툴면 가끔 GAME OVER. 한 스테이지는 약 1.5~4분.

## 5. 파일 구조 (`piano-bricks/`)

게임은 `index.html` 하나입니다. 화면 구성(타이틀, 곡 선택, 새 곡 만들기, 결과) 뒤에 `<style>` 하나와 `<script>` 하나가 있고,
스크립트는 아래 순서의 부분으로 나뉩니다 (각 부분은 `/* ===== js/이름.js ===== */` 주석으로 시작).

| 부분 | 내용 |
|---|---|
| `songs` | 곡·스테이지 데이터 (멜로디, 코드, 전곡 순서) — 새 곡은 여기에 추가 |
| `core` | 화면 배치 상수, 스테이지 생성(방해 블럭 배치·난이도), 공 물리 |
| `maker` | 맵 만들기: 멜로디→스테이지, Claude 답 해석, MIDI 파서, 음악 분석 |
| `audio` | WebAudio 신스 (피아노 음, 틀린 음, 반주, 효과음, 배경 반주·바람) |
| `game` | 게임 진행, 그리기, 입력, 결과/메뉴 화면, 진행도 저장(localStorage) |
| `create` | 새 곡 만들기 화면 |

곡 데이터 형식 예 (`index.html`의 songs 부분):
```js
{ melody: 'E4 E4 B4 B4 C#5 C#5 B4:2', chords: 'E E A E' }  // 음이름:박자, R = 쉼표
```

## 6. 실행 방법
- 저장소를 받아 작업 브랜치로 바꾼 뒤 `piano-bricks/index.html`을 브라우저로 열기
- 빌드 과정 없음 (HTML5 파일 하나, 서버 없이 파일을 바로 열어도 됨)
- GitHub Pages를 켜면 `…github.io/etc/piano-bricks/` 주소로도 실행 가능 (단, 제목으로 만들기는 claude.ai 아티팩트에서만 동작)

## 7. 확인한 것 / 아직 못 한 것
**확인함**
- 휴대폰·데스크톱 크기 브라우저에서 타이틀 → 곡 선택 → 스테이지 → 재생 → 결과 → GAME OVER → 전곡 듣기 → 새 곡 만들기 자동 테스트 통과
- 발판 받기, 아이템 획득, 검은 블럭 통과 동작
- 음악 분석: 테스트 음원에서 템포 100·108·126 BPM 정확, 멜로디 음높이 97% 일치. MIDI 100% 일치

**못 한 것**
- 실제 귀로 소리 확인(음량·음색은 분석값으로만 맞춤), 실제 휴대폰 터치감 확인
- 실제 Claude 호출(제목으로 만들기)은 가짜 Claude로만 흐름 확인
- 실제 가요·팝 MP3 분석 (반주가 많으면 멜로디 대신 다른 악기를 잡을 수 있음)
- 만든 곡은 브라우저(기기)별 저장이라 다른 기기와 공유 안 됨

## 9. 로컬 Claude Code로 옮기기

   ```bash

   cd etc
   claude --teleport
   ```
