# 피아노 블록 퍼즐

모바일 세로 화면용 HTML5 게임. 피아노 롤 위로 흘러오는 노트를 블록 블라스트식 블록으로 덮어서 곡을 연주한다.

## 화면

- **상단: 피아노 롤 (보드)** — 왼쪽에 세로 건반, 오른쪽에 노트 격자. 재생선은 가운데 고정이고 노트가 오른쪽에서 왼쪽으로 흘러온다.
- **하단: 블록 3개** — 끌어서 피아노 롤 위에 놓는다. 3개를 다 쓰면 새로 3개가 나온다.

## 규칙

| 상황 | 결과 |
| --- | --- |
| 초록 노트 칸을 덮음 | 칸당 +100. 재생선을 지날 때 그 음이 울리고 건반이 빛난다 |
| 빈칸을 덮음 | 칸당 −50. 회색 블록으로 남는다 |
| 빈칸 없이 딱 맞춤 | 콤보 +1, 콤보가 쌓일수록 점수 배율 증가 (최대 3배) |
| 한 마디의 노트를 전부 덮음 | 마디 완성 +500 |
| 덮지 않은 노트 | 소리 없이 지나간다 |

- 재생선을 이미 지났거나 지나는 중인 칸에는 놓을 수 없다.
- 블록 3개 중 최대 2개는 다가오는 노트 모양에 딱 맞게 만들어지고, 나머지는 랜덤 모양이다.
- 결과 화면의 별은 정확도(덮은 노트 칸 / 전체 노트 칸) 기준: 40% / 65% / 85%.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 웹 서버로 띄운다.

```bash
npx serve piano-block-puzzle
# 또는
python3 -m http.server -d piano-block-puzzle 8000
```

## 구조

```
index.html      화면 마크업 (HUD, 메뉴, 일시정지, 결과)
style.css
js/main.js      메뉴·HUD·결과 화면 연결, 최고 기록 저장(localStorage)
js/game.js      게임 본체: 레이아웃, 시계/오디오 예약, 입력, 캔버스 그리기
js/pieces.js    블록 모양과 트레이 생성
js/songs.js     곡 데이터와 파서
js/audio.js     Web Audio 합성 피아노 (샘플 파일 없음)
```

## 곡 추가

`js/songs.js`의 `DEFS`에 항목을 추가한다. 트랙은 `음이름[:길이]` 토큰을 공백으로 나열한다.

```js
{
  id: 'mysong',
  title: '곡 제목',
  composer: '작곡가',
  level: 1,          // 1~3
  stepSec: 0.5,      // 한 칸의 길이(초)
  stepsPerBeat: 1,   // 한 박 = 몇 칸
  stepsPerBar: 4,    // 한 마디 = 몇 칸
  tracks: ['C4 D4 E4:2 | R:2 G4+C5:2'], // R = 쉼표, + = 화음, | = 마디 구분(무시)
}
```

한 칸이 0.45~0.6초 정도일 때 블록을 옮길 시간이 넉넉하다.
