# 피아노 블록

모바일 세로 화면용 HTML5 음악 퍼즐 게임. 피아노 롤의 노트 위에 블록 블라스트식 블록을 맞춰 놓아 곡을 연주한다.

## 화면

- **상단: 피아노 롤 (보드)** — 왼쪽에 악기 패널(피아노 건반 / 드럼 이름 / 보컬 도레미), 오른쪽에 노트 격자. 재생선은 보드 왼쪽에서 한 칸 위치에 고정되고 노트가 오른쪽에서 왼쪽으로 흘러온다.
- **하단: 블록 3개** — 끌어서 보드 위에 놓는다. 3개를 다 쓰면 새로 3개가 나온다. 가끔 폭탄 블록이 섞여 나온다.

## 모드

메뉴의 **진행 방식**(30초 정지 / 자동 이동)은 곡 연주, 합주, 자유 작곡 모두에 적용된다.

| 모드 | 진행 |
| --- | --- |
| 곡 연주 · 30초 정지 | 한 페이지를 30초 동안 멈춰 두고 채운다. 시간이 끝나거나, 노트를 다 채우거나, `바로 연주`를 누르면 그 페이지만 흘러가며 연주하고 다음 페이지로. 마지막에 곡 전체를 이어서 연주한다. |
| 곡 연주 · 자동 이동 | 곡 템포대로 쉬지 않고 흘러간다. 재생선에 닿기 전에 흘러오는 노트 위에 놓아야 한다. |
| 합주 · 30초 정지 | 페이지마다 피아노 → 드럼 → 보컬 순서로 한 장씩(각 30초) 채우고, 그 페이지를 세 악기 합주로 짧게 들려준다. 다음 페이지도 같은 순서. 마지막에 전체 합주. |
| 합주 · 자동 이동 | 순서는 같고, 악기 페이지마다 오른쪽에서 흘러오는 동안(카운트인 포함) 블록을 놓는다. 페이지를 다 채우면 `ALL CLEAR` +300. |
| 자유 작곡 | 목표 노트 없이 빈 피아노 롤에 놓은 블록이 그대로 음이 된다. 하단 블록마다 놓기 좋은 자리를 같은 색 반투명 블록으로 추천한다(다장조 흰 건반, 앞 음과 이어지는 음정, 어울리는 화음, 빈 박 우선). 메뉴의 `추천 블록`으로 끌 수 있다. 30초 정지 방식에서는 시간 제한 없이 `다음 페이지`로 넘기고, 자동 이동 방식에서는 흘러가는 대로 놓는다(최대 32마디). `완성`으로 전체 연주. |

## 노래 제목으로 레벨 만들기

메뉴의 입력칸에 노래 제목을 넣고 난이도(쉬움/보통/어려움)를 골라 `만들기`를 누르면 그 곡으로 새 레벨이 생긴다. 만든 레벨은 `내가 만든 레벨` 목록에 저장되고(최대 30개, localStorage), 곡 연주처럼 진행 방식(30초 정지/자동 이동)을 따른다. 같은 제목으로 다시 만들면 예전 레벨을 새 것으로 바꾸고, `삭제`를 두 번 누르면 지운다.

- **claude.ai에서 열었을 때**: 페이지가 Claude에게 멜로디를 부탁한다(아티팩트 `sample` 기능, 보는 사람의 Claude 사용량을 쓰고 처음 한 번 허락을 묻는다). 저작권이 끝난 곡(민요·동요·옛 찬송가·작곡가 사후 70년이 지난 클래식)은 원곡 멜로디로, 그 밖의 곡이나 모르는 제목은 제목 분위기에 맞춘 새 멜로디로 만든다. 저작권이 있는 멜로디는 옮기지 않는다. 목록에 `원곡 멜로디` / `새 멜로디`로 표시된다.
- **그 밖의 환경이거나 Claude를 쓸 수 없을 때**: 제목을 씨앗으로 한 자동 작곡으로 만든다(`자동 작곡`). 제목에 '슬픈·비·밤·이별' 같은 말이 있으면 가단조와 느린 템포, '신나는·여름·파티' 같은 말이면 빠른 다장조, '왈츠·자장가'면 3/4박자. 4마디 악절을 화음 진행 위에 짓고 반마침·온마침으로 끝낸다. 같은 제목과 난이도는 늘 같은 곡이 된다.
- 받은 악보는 검사해서 한 줄 멜로디로 정리한다: 화음은 맨 위 음만, 앞쪽 빈 마디 제거, 최대 16마디, 음역은 C4~C5 근처로 옮김. 8분음표가 없으면 4분음표 = 1칸 격자로 바꿔 칸을 넓힌다. 난이도 별은 실제 악보(8분음표 비율, 음역)로 매긴다.

## 스토리 · 건반 위의 약속

메뉴 맨 위의 비주얼 노벨 모드. 이어하기가 자동 저장된다(장면 단위).

- 등장인물: 이도현(20, 악보 없이 귀로 익힌 독학 천재), 한서윤(27, 손목 부상으로 무대를 떠난 아카데미 강사), 한정훈(서윤의 아버지, 한국대 음대 교수), 강태준(서윤의 약혼자, 한국대 이사장 아들인 재벌 2세 · 아버지가 정한 정략 약혼), 윤채아(21, 작년 우승자이자 한 교수의 제자)
- 1장 지역 대회: 역 광장 → 첫 레슨(연습 연주) → 밤의 연습실 → 아버지 등장과 미니게임 → 약혼자 등장 → 라이벌 → 약혼 발표 파티(연탄 미니게임) → 저택 테라스 → 결선 곡 고르기 → 결선 연주 → 심사 → 우승/준우승
- 선택지마다 호감도와 실력이 오르고, 이후 대사와 엔딩이 갈린다
- 결선 심사 점수 = 연주 정확도 × 60 + 곡 난이도 × 6 + 별 × 3 + 실력(최대 10) + 호감도 ÷ 2(최대 4). 라이벌 78.0점보다 높으면 우승, 아니면 결선 준비로 돌아가 재도전
- 미니게임 「들키지 마!」: 버튼을 누르고 있는 동안은 `선생님 쳐다보기`(마음 게이지가 찬다), 떼면 `안 보는 척`. 유리문 너머 아버지(교수)가 `!` 하고 돌아보려 하면 손을 떼야 한다. 돌아본 동안 누르고 있으면 들킨 횟수 +1, 3번이면 실패. 26초 안에 게이지를 채우면 성공. 결과(성공/들킴/시간 초과)에 따라 이후 대사가 달라진다
- 미니게임 「비밀 연탄곡」(약혼 발표 파티): 강 이사장 저택에서 서윤과 한 피아노에 나란히 앉아 미뉴에트를 연탄으로 친다. 서윤이 반주(자동), 도현이 멜로디. 리듬 게임 두 줄:
  - 왼쪽 `건반`: 흘러내리는 건반 타일이 판정선에 닿을 때 누르면 그 음이 울린다(PERFECT ±0.08초, GOOD ±0.16초). 놓치면 소리가 비고, 앞 테이블의 강태준이 곧 돌아본다
  - 오른쪽 `♥ 신호`: 서윤의 눈짓. 태준이 손님과 건배하는 동안(`!` 경고 중에도) 받으면 마음 게이지가 찬다(8개면 가득). 태준이 보는 동안 받으면 들킨 횟수 +1, 3번이면 실패
  - 결과: 곡 끝까지 마음 게이지를 채우면 성공, 3번 들키면 실패, 못 채우면 「끝내 눈을 못 맞췄다」. 결과와 연주 정확도(80% 이상이면 실력 +1)에 따라 이후 대사가 달라진다. 키보드는 ←/F, →/J
- 연주는 메뉴의 진행 방식(30초 정지/자동 이동)을 따르고, 결과 화면의 `스토리 계속`으로 돌아온다

모두 저작권이 끝난 곡이다. 같은 이름의 곡은 곡 연주와 합주(피아노·드럼·보컬 편곡) 양쪽에 있다.

## 규칙

| 상황 | 결과 |
| --- | --- |
| 노트 위 칸을 덮음 | 그 칸이 **하얀색**으로 바뀐다. 칸당 +100. 재생선을 지날 때 그 음이 울리고 왼쪽 패널이 빛난다 |
| 노트 밖 칸을 덮음 | 블록 원래 색 그대로 남는다. 칸당 −50. 재생선을 지날 때 그 줄의 음(드럼은 그 악기, 보컬은 그 계이름)으로 연주된다 |
| 블록을 놓을 때 | 덮은 줄의 건반(드럼/보컬) 소리가 난다 |
| 빈칸 없이 딱 맞춤 | `FANTASTIC`, 콤보 +1, 콤보가 쌓일수록 점수 배율 증가 (최대 3배) |
| 절반 이상 맞춤 | `GOOD`, 콤보 끊김 |
| 절반 미만 | `BAD`, 화면 흔들림 |
| 보관함 | 안 쓰는 블록을 하단 오른쪽 보관함에 끌어다 두면 최대 9개까지 쌓인다(쌓인 수량 배지 표시). 보관함에서 끌어내면 맨 위 블록부터 쓴다. 보관함에 넣은 블록은 트레이에서 쓴 것으로 친다 |
| 폭탄 블록 | 놓은 모양 안의 블록을 터뜨려 지운다. 노트 밖 블록을 지우면 냈던 감점을 돌려받고, 노트 위 블록을 지우면 그 점수를 잃는다 |
| 정지 모드에서 페이지를 다 채움 | `ALL CLEAR` +300 + 남은 초 × 10 |
| 덮지 않은 노트 | 소리 없이 지나간다 |
| 한 페이지 연주가 끝남 | 보드 위에 그 페이지에서 얻은 점수와 연주 %(덮은 노트 칸 비율) 카드를 띄운다. 자동 이동에서는 재생선이 페이지 경계를 지날 때마다 |

상단에는 점수 옆에 곡 전체의 **연주 %**(전체 노트 칸 중 덮은 칸)가 실시간으로 표시된다. `원곡 듣기`는 노트만 연주한다.

결과 화면의 별은 정확도(덮은 노트 칸 / 전체 노트 칸) 기준: 40% / 65% / 85%. 결과 화면에서 내가 만든 연주(`다시 듣기`)와 `원곡 듣기`를 들을 수 있다.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 웹 서버로 띄운다.

```bash
npx serve piano-block-puzzle
# 또는
python3 -m http.server -d piano-block-puzzle 8000
```

```

js/instruments.js   악기별 줄 배치(피아노 반음 / 보컬 도레미 / 드럼 6종)와 색

js/audio.js         Web Audio 합성 악기: 피아노, 보컬(포먼트), 드럼 (샘플 파일 없음)
js/draw.js          블록·폭탄 그리기 도우미
js/story.js         스토리 모드 엔진 (대사, 선택지, 연주 연동, 심사, 미니게임 2종)
js/story-data.js    스토리 대본과 등장인물
js/portraits.js     캐릭터 일러스트 (SVG, 표정 6종)
```

## 곡 추가

`js/songs.js`의 `SONG_DEFS`(곡 연주) 또는 `BAND_DEFS`(합주)에 항목을 추가한다. 트랙은 `음이름[:길이]` 토큰을 공백으로 나열한다.

```js
{
  id: 'mysong',
  title: '곡 제목',
  composer: '작곡가',
  level: 1,          // 1~3
  stepSec: 0.5,      // 한 칸의 길이(초)
  stepsPerBeat: 1,   // 한 박 = 몇 칸
  stepsPerBar: 4,    // 한 마디 = 몇 칸
  sceneSteps: 12,    // 한 페이지 = 몇 칸 (화면 폭이 이 칸 수에 맞춰진다)
  parts: {
    piano: ['C4 D4 E4:2 | R:2 G4+C5:2'], // R = 쉼표, + = 화음, | = 마디 구분(무시)
    // 합주 곡은 drums, vocal 도 추가
    // drums: ['KK R SN R | ...'],  CR 크래시 · HH 하이햇 · TH 하이탐 · TL 로우탐 · SN 스네어 · KK 킥
    // vocal: ['C4:2 E4:2 | ...'],  도레미(다장조 음계) 음만 쓴다
  },
}
```
