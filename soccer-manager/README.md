# 터치라인 매니저

축구 감독이 되어 5부 리그 구단을 1부 리그 챔피언으로 키우는 **방치형 축구 RPG**입니다.
경기는 자동으로 흘러가고, 선수들은 경기와 훈련으로 경험치를 쌓습니다. 감독은 골드로 레벨업하고,
스카우트로 높은 등급 선수를 뽑고, 경기에서 얻은 장비를 강화하고, 감독 특성을 찍습니다.
빌드 도구나 의존성 없이 브라우저에서 바로 돌아갑니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
cd soccer-manager
python3 -m http.server 8000   # http://localhost:8000
```

진행 상황은 5초마다 브라우저(localStorage)에 자동 저장됩니다. 설정 탭의 저장 코드로 다른 브라우저에 옮길 수 있습니다.

## 성장 시스템

| 요소 | 내용 |
| --- | --- |
| 등급 | 일반 · 희귀 · 영웅 · 전설 · 신화. 등급이 높을수록 기본 능력치와 레벨당 성장치가 크다 |
| 레벨 | 경기 출전과 훈련으로 경험치가 쌓여 자동으로 오르고, 골드를 내면 즉시 올릴 수 있다. "선발 일괄 레벨업"은 가장 싼 레벨업부터 자금이 허락하는 만큼 |
| 돌파 ★ | 레벨 상한(★1 20 → ★5 60)에 닿으면 돌파석과 골드로 돌파. OVR +2, 상한 +10 |
| 스킬 | 선수마다 하나. 패시브(팀 공격·수비 가산), 발동(경기 중 대포알 슛·프리킥), 방어(슈퍼 세이브·슬라이딩 태클로 실점 저지). 스킬북으로 Lv.10까지 |
| 장비 | 축구화·보호구 두 칸. 경기에서 이기면 드롭(승 40% · 무 18% · 패 6%), 골드로 +15까지 강화, 자동 장착·일괄 분해 |
| 스카우트 | 일반(골드, 10회 시 희귀 이상 보장) · 프리미엄(티켓, 10회 시 영웅 이상 보장). 스쿼드(30명)가 차면 돌파석으로 전환 |
| 감독 | 경기·시즌 결과로 감독 레벨이 오르고, 레벨마다 특성 포인트. 공격 전술가 · 수비 전술가 · 명 트레이너 · 재무 전문가 · 협상가 · 카리스마 |
| 명성 | 1부 리그 우승마다 +1. 1부 상대가 +2.5씩 강해지고 수입이 20%씩 늘어나는 끝없는 엔드게임 |

자원은 네 가지입니다: **자금**(입장료·중계권·스폰서·굿즈·상금), **프리미엄 티켓**(시즌 보상·업적·감독 5레벨마다),
**돌파석**(승리 전리품·시즌 보상·방출), **스킬북**(승리 전리품·시즌 보상). 주급은 없고, 번 돈은 전부 성장과 시설에 씁니다.

## 화면

| 화면 | 하는 일 |
| --- | --- |
| 매치데이 패널 | 전광판·피치·문자 중계. 스킬이 발동하면 피치에 표시된다. 경기당 두 번 **감독 지시**(총공격·집중력·잠그기) |
| 구단 | 라운드당 예상 수입, 홈 관중, 구단주 목표, 재정 장부, 지난 경기 전리품, 구단 소식 |
| 선수단 | 포메이션·전술, 선수 목록과 레벨업. 이름을 누르면 상세 창에서 레벨업·돌파·스킬·장비·방출 |
| 스카우트 | 일반·프리미엄 스카우트와 등급별 확률, 유스 아카데미 콜업 |
| 장비 | 가방(60칸), 장착 선수 지정, 강화, 분해 |
| 감독 | 감독 레벨과 특성 트리, 특성 초기화 |
| 시설 | 경기장·훈련장·유소년 아카데미·메디컬 센터·구단 스토어·스카우트 네트워크 (각 Lv.10) |
| 리그 | 8팀 더블 라운드로빈(14라운드). 상위 2팀 승격, 하위 2팀 강등 |
| 기록 | 트로피, 통산 기록, 시즌별 기록, 업적 24종 |

- **시간**: 1배속 기준 한 라운드 약 68초, 한 시즌 약 16분. 1·2·4·8배속과 일시정지
- **오프라인 진행**: 창을 닫아도 실제 시간 최대 2시간까지 절반 속도로 구단이 돌아갑니다. 시즌이 끝나면 비시즌에서 멈춰 새 시즌 개막은 감독에게 맡깁니다
- **이전 저장본**: 구단 운영판(v1) 저장본은 불러올 때 자동으로 RPG판으로 옮겨집니다(잠재력으로 등급을 정하고 능력치는 보존, 보상 티켓 5장)

## 구조

```
soccer-manager/
├── index.html              화면 뼈대
├── style.css               스타일(라이트/다크, 구단 색은 JS가 주입)
├── js/engine.js            게임 엔진 — DOM 없는 순수 로직, Node에서 테스트
├── js/storage.js           localStorage 저장, 저장 코드, 아티팩트 계정 저장
├── js/ui.js                렌더링과 입력 처리, 250ms 게임 루프
├── test/engine.test.js     엔진 단위 테스트 (node:test)
└── scripts/
    ├── simulate.js         자동 감독으로 N시즌 돌려 보는 밸런스 시뮬레이션
    └── build-artifact.js   claude.ai 아티팩트용 단일 HTML 빌드
```

## 개발

```bash
npm test                         # 엔진 테스트
npm run simulate -- 16 7         # 16시즌, 시드 7로 밸런스 확인
npm run build:artifact           # dist/touchline-manager.html 생성
```

밸런스 수치는 `js/engine.js` 위쪽 상수(`TIERS`, `ECON`, `GRADES`, `SKILLS`, `ITEM_STAT`, `TALENTS`, `T`)에 모여 있습니다.
간단한 규칙으로 움직이는 자동 감독은 대략 6~8시즌(1배속 약 1.5~2시간)에 1부 리그에 오르고, 9~14시즌에 첫 1부 우승을 합니다.
