# 터치라인 매니저

축구 감독이 되어 5부 리그 구단을 1부 리그 챔피언으로 키우는 방치형 웹 게임입니다.
경기는 자동으로 흘러가고, 감독은 영입·시설 투자·전술·유스 육성을 맡습니다.
빌드 도구나 의존성 없이 브라우저에서 바로 돌아갑니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
cd soccer-manager
python3 -m http.server 8000   # http://localhost:8000
```

진행 상황은 5초마다 브라우저(localStorage)에 자동 저장됩니다. 설정 탭의 저장 코드로 다른 브라우저에 옮길 수 있습니다.

## 게임 방법

| 화면 | 하는 일 |
| --- | --- |
| 매치데이 패널 | 전광판·피치·문자 중계로 경기를 지켜봅니다. 경기당 두 번 **감독 지시**(총공격·집중력·잠그기, 15분 유지)를 내릴 수 있습니다. |
| 구단 | 라운드당 손익, 홈 관중, 구단주 목표, 재정 장부, 구단 소식 |
| 선수단 | 포메이션(4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2)과 전술 선택. 선발 11명은 컨디션까지 따져 자동 선발되고, 지친 선수는 휴식으로 뺄 수 있습니다. |
| 이적시장 | 3라운드마다 새 매물. 잠재력은 스카우트 추정치로 보입니다. 시즌이 끝나면 유스 유망주가 콜업 대기합니다. |
| 시설 | 경기장·훈련장·유소년 아카데미·메디컬 센터·구단 스토어·스카우트 네트워크 (각 Lv.10까지) |
| 리그 | 8팀 더블 라운드로빈(14라운드). 상위 2팀 승격, 하위 2팀 강등 |
| 기록 | 트로피, 통산 기록, 시즌별 기록, 업적 18종 |

- **시간**: 1배속 기준 한 라운드 약 68초(준비 15초 · 경기 45초 · 하프타임 3초 · 종료 5초), 한 시즌 약 16분. 상단에서 1·2·4·8배속과 일시정지를 고릅니다.
- **수입**: 홈 경기 입장료(관중 = 팬 수와 최근 성적, 경기장 좌석 수 상한), 중계권, 스폰서, 굿즈 판매, 승리 수당, 시즌 상금, 승격 보너스, 구단주 목표 보상, 업적 보상
- **지출**: 매 라운드 선수 주급(능력치에 따라 오름), 이적료, 시설 공사비
- **성장**: 선수는 나이와 잠재력, 훈련장 레벨에 따라 실시간으로 성장하고, 출전하면 조금 더 큽니다. 31세부터 노쇠하고 33세 이후 은퇴할 수 있습니다.
- **오프라인 진행**: 창을 닫아도 실제 시간 최대 2시간까지 절반 속도로 구단이 돌아갑니다. 시즌이 끝나면 비시즌에서 멈춰 새 시즌 개막은 감독에게 맡깁니다.

## 구조

```
soccer-manager/
├── index.html              화면 뼈대
├── style.css               스타일(라이트/다크, 구단 색은 JS가 주입)
├── js/engine.js            게임 엔진 — DOM 없는 순수 로직, Node에서 테스트
├── js/storage.js           localStorage 저장, 저장 코드, 아티팩트 계정 저장
├── js/ui.js                렌더링과 입력 처리, 250ms 게임 루프
├── test/engine.test.js     엔진 단위 테스트 (node:test)
└── scripts/
    ├── simulate.js         자동 감독으로 N시즌 돌려 보는 밸런스 시뮬레이션
    └── build-artifact.js   claude.ai 아티팩트용 단일 HTML 빌드
```

## 개발

```bash
npm test                         # 엔진 테스트
npm run simulate -- 25 7         # 25시즌, 시드 7로 밸런스 확인
npm run build:artifact           # dist/touchline-manager.html 생성
```

밸런스 수치는 `js/engine.js` 위쪽의 `TIERS`, `ECON`, `FACILITIES`, `T`(시간) 상수에 모여 있습니다.
간단한 규칙으로 움직이는 자동 감독은 대략 13~16시즌(1배속 약 3.5~4시간)에 1부 리그에 오르고, 20시즌 이후 1부 우승을 노립니다.
