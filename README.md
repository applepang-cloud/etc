## 🎹 피아노 브릭스 (Piano Bricks)

원곡 멜로디는 지키고 방해 음 블럭만 깨는 **스테이지형 피아노 벽돌깨기** 게임입니다.
[`piano-bricks/`](piano-bricks/) 폴더에 있으며, 빌드 없이 `piano-bricks/index.html`을 브라우저로 열면 바로 실행됩니다.
(GitHub Pages를 켜면 `/piano-bricks/` 주소로 휴대폰에서도 플레이할 수 있어요.)

### 화면
- 왼쪽: 피아노 건반, 가운데: **재생 라인**, 오른쪽: 음 블럭이 놓인 보드(피아노 롤)
- 아래 청록색 영역에서 공을 조준해 발사합니다.

### 규칙
| 블럭 | 의미 | 공에 맞으면 |
|---|---|---|
| ⬜ 흰 블럭 / ⬛ 검은 블럭 | 원곡 멜로디 (흰 건반 음 / 검은 건반 음) | 안 깨짐 (튕기며 그 음이 울림) |
| 🟦🟩🟥🟨🟪 컬러 블럭 | 방해 음 (숫자 = 체력) | 깨짐 |

- 한 스테이지 = 노래의 한 소절(8박), 한 스테이지당 **30번 발사**
- 발사할 때마다 보드가 재생 라인 쪽으로 흘러갑니다.
- 30번이 끝나면(또는 방해 블럭을 다 깨면) 보드가 재생 라인을 지나가며 연주됩니다. 남은 방해 블럭은 **틀린 음**으로 연주돼요.
- 남은 방해 블럭 **0개 ★★★ · 1~5개 ★★ · 6~10개 ★ · 11개 이상 GAME OVER**
- 한 곡의 모든 스테이지를 클리어하면 **전곡 듣기**로 곡 전체를 연주합니다 (남겨 둔 방해 블럭도 함께 연주됨).

### 수록곡 (모두 저작권 만료 곡)
작은 별(3스테이지) · 비행기(3) · 징글벨(5) · 환희의 송가(5)

### 조작
- 터치/마우스: 위쪽을 눌러 조준 → 손을 떼면 발사
- 키보드: ← → 조준, Space/Enter 발사

### 코드 구조
레벨을 데이터 파일로 분리한 [jakesgordon/javascript-breakout](https://github.com/jakesgordon/javascript-breakout)의 구조를 참고했습니다.

| 파일 | 내용 |
|---|---|
| `js/songs.js` | 곡·스테이지 데이터 (멜로디, 코드, 전곡 순서) — 새 곡은 여기에 추가 |
| `js/core.js` | 화면 배치 상수, 스테이지 생성(방해 블럭 배치·난이도), 공 물리 |
| `js/audio.js` | WebAudio 신스 (피아노 음, 틀린 음, 반주, 효과음) |
| `js/game.js` | 게임 진행, 그리기, 입력, 결과/메뉴 화면, 진행도 저장(localStorage) |
