## 별빛 멜로디 (`starlight-melody/`)
경음부 키보디스트인 주인공이 여섯 명의 여성 보컬을 만나 축제 무대를 준비하는 도트 서브컬처 연애 시뮬레이션. 합주 장면은 음표 퍼즐(노노그램)이고, 퍼즐판이 곧 8스텝 시퀀서라 풀수록 곡이 완성된다.

- 단일 HTML 파일 (`starlight-melody/index.html`), 외부 이미지나 사운드 파일 없음
- 12주 진행: 매주 연습(연주·작곡·센스) / 학교 둘러보기(첫 만남) / 만나러 가기(선택지 대화) / 합주(퍼즐) 중 하나
- 히로인 6명: 리아(옥상), 유나(음악실), 하나(체육관), 소라(도서관), 아린(상점가), 세나(방송실). 각자 호감도, 대화 이벤트 3개, 능력치 조건 선택지, 전용 곡 5소절
- 엔딩: 호감도 70 이상 + 전용 곡 완성 → 연애 엔딩, 그 외 우정·솔로 엔딩. 연애 엔딩 수집 기록 저장
- 그 밖의 모드: 자유 연주(6곡), 풀이 연습(노노그램 요령 튜토리얼)
- 멜로디 악기 6종, 리듬·반주 줄 7종 (Web Audio 합성)
- 모든 소절은 찍기 없이 줄 논리만으로 풀리도록 힌트(별 칸) 배치를 검증함
- 캐릭터 도트 일러스트는 코드로 생성 (`drawHeroine({char})`, 96×108, 표정 4종)
