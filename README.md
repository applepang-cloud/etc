## 별빛 멜로디 (`starlight-melody/`)
한국의 별빛고 밴드부 키보디스트인 주인공이 여섯 명의 여성 보컬을 만나 축제 무대를 준비하는 도트 서브컬처 연애 시뮬레이션. 합주 장면은 음표 퍼즐(노노그램)이고, 퍼즐판이 곧 8스텝 시퀀서라 풀수록 곡이 완성된다.

- 게임 본체는 HTML 파일 하나(`starlight-melody/index.html`). 일러스트·악기·효과음은 파일 안에 들어 있어서 이것만 열어도 돌아간다
  - `voice/` 폴더(히로인 대사 429개 + 터치 반응 30개 + 주인공 독백 90개)가 옆에 있으면 대사를 목소리로 읽어 준다. 없으면 글자만 나온다
  - `bgm/` 폴더(배경 음악 4곡)도 같은 식으로, 있으면 장면마다 깔린다
  - `music-map-server.js`는 AI 뮤직맵을 쓸 때만 필요하다(아래)
- 화면 전체를 캔버스 하나(360×640 세로 기준)에 그리고 창 크기에 맞춰 비율 그대로 확대·축소. 대화창·버튼·퍼즐판·상태창·도움말 모두 캔버스에 그리며, 이름·노래 검색 입력 칸만 한글 입력기를 위해 실제 입력 상자를 겹쳐 씀
- 저장 슬롯 3개(새 게임·이어 하기에서 고름. 예전 저장은 1번 슬롯)
- 설정(타이틀): 배경 음악·효과음과 연주·목소리를 각각 끔/작게/보통/크게, 글자 속도 보통/빠르게/즉시, 자동 넘기기(이야기 장면에서 글과 목소리가 끝나면 다음으로). 위쪽 막대의 '빠르게'와 '소리 끄기'로도 바로 바꿀 수 있음
- 조작: 터치·마우스(칸 누르기, 줄 따라 끌기), 키보드(방향키로 칸 이동 후 Space/Enter, Tab으로 버튼 이동, 숫자키로 선택지, H 힌트, Esc 도움말 닫기)
- 1년 진행(3월 1주 ~ 이듬해 2월 4주, 48주): 한 주에 행동 3번 — 연습(연주·작곡·센스) / 둘러보기(첫 만남) / 만나러 가기(대화) / 합주(퍼즐) / 주말 데이트(한 주 한 번, 호감도 30부터) / 쉬기
  - 컨디션: 연습·합주로 줄고 쉬기·데이트·주말로 회복. 25 아래면 연습 효과가 줄어든다
  - 대화 이벤트는 히로인마다 12개(봄·여름·가을·겨울로 이어짐), 호감도가 쌓여야 다음 이야기가 열린다. 6주 넘게 못 만나면 서운해하며 호감도가 조금씩 내려간다
  - 두근 이벤트(호감도 50·75를 처음 넘을 때 단둘이 있는 장면), 생일(히로인별 생일 주에 선물 고르기: 좋아함·보통·별로), 문자(가끔 주가 바뀔 때 친한 히로인에게서 계절 문자)
  - 연습곡 퍼즐 3권(권마다 12소절, 풀면 연주·작곡 +1, 별 3개면 센스 +1). 2권(기타, 6~7줄)은 여름부터 또는 1권을 끝내면, 3권(바이올린, 7줄, 별 칸 거의 없음)은 겨울에 2권을 끝내면 열리고, 2·3권 새 소절은 연주·작곡 +2
  - 허브: 3주 안에 다가오는 행사·생일·축제를 미리 보여 주고, 히로인 카드를 누르면 프로필(학년·장소·생일·좋아하는 선물·대화·곡 진행)
  - 친구 민준에게 전화(허브 위 ☎ 민준, 한 주 한 번, 행동 안 씀): 히로인별 소문(호감도 단계에 따라 다른 말), 못 만난 히로인 찾는 곳, 좋아하는 능력치·데이트 장소·생일 선물, 오래 안 만나면 서운해한다는 경고, 내 실력 평가. 통화 장면은 코덱스 도트 일러스트, 목소리는 ElevenLabs로 따로 만든 장난스러운 남자 목소리
  - 행동 사이 우연한 만남(25%), 데이트 장소 6곳(카페·노래방·영화관·놀이공원·한강공원·여름 바다)마다 히로인별 좋아함/보통/별로
  - 학교 행사 18개: 동아리 박람회, 벚꽃길, 중간고사, 체육대회, 장마, 방학식, 해수욕장, 한강 불꽃축제, 추석, 중간 리허설, 축제 전야, 축제 뒤풀이, 수능 응원, 첫눈, 크리스마스 버스킹, 새해 해돋이, 발렌타인데이, 졸업식. 가장 친한 히로인이 등장하고, 체육대회·해수욕장·크리스마스에는 즉석 합주 퍼즐
- 히로인 6명: 리아(옥상), 유나(음악실), 하나(체육관), 소라(도서관), 아린(시장 떡집), 세나(방송실). 각자 호감도, 대화 이벤트 12개, 능력치 조건 선택지, 전용 곡 2곡(각 5소절, 첫 곡을 끝내면 두 번째 곡)
- 축제 라이브(10월 3주): 축제 날 함께 무대에 설 히로인을 직접 고르고(호감도 45 이상 또는 전용 곡 완성), 무대 위에서 그 곡의 라스트 소절(6번째 퍼즐)을 푼다
  - 관객 열기 게이지: 맞히면 오르고, 줄을 완성하면 추가로 오르고, 틀리거나 힌트를 쓰거나 시간이 흐르면 내려간다
  - 능력치 효과: 센스는 시작 열기와 식는 속도, 연주는 실수 감점, 작곡은 미리 채워진 별 칸 수
  - 응원봉 관객 연출(열기만큼 불이 켜지고 75% 이상이면 박자에 맞춰 뜀), 함성 효과음, S/A/B/C 결과 카드
  - 등급 보너스(S +15, A +10, B +5, C 0)가 호감도에 더해지고, 전용 곡을 완성했다면 라스트 소절까지 6소절 앵콜 연주
- 장면 배경 22장: 히로인 장소 6곳(옥상·음악실·체육관·도서관·시장 떡집·방송실), 데이트 장소 5곳, 행사 11개(벚꽃길·체육대회·장마·해수욕장·불꽃축제·추석 시장·축제 무대·첫눈·크리스마스 거리·해돋이·졸업식). 코덱스 GPT 이미지로 그린 뒤 176×176 도트로 줄임. 허브·타이틀·엔딩 옥상은 별하늘 그대로
- 두근 CG: 호감도 75 두근 이벤트(고백 직전 장면)에 히로인별 일러스트
- 라이브 CG: 축제 라이브 결과 화면에 무대 위에서 노래하는 히로인 일러스트(응원봉 객석, 주인공의 건반 시점)
- 엔딩 CG: 연애 엔딩 고백 장면에 별빛 옥상 일러스트(코덱스 GPT 이미지 → 240×160 도트). 타이틀의 앨범은 CG 18장(히로인마다 두근·라이브·엔딩) 갤러리로, 한 번 본 CG는 새 게임을 해도 남는다
- 겨울 별빛 콘서트(2월 1주): 두 번째 곡을 완성한 히로인과 응원봉 객석 앞에서 그 곡 전곡 공연
- 엔딩(2월 종업식 밤, 옥상): 가장 친한 히로인이 기다린다. 호감도 80 이상(축제를 함께했다면 +10) + 첫 곡 완성 → 고백하는 연애 엔딩, 그 외 우정 엔딩, 아무도 못 만났으면 솔로 엔딩. 연애 엔딩 수집 기록 저장
- 그 밖의 모드: 자유 연주(쪽 넘김), 풀이 연습(처음 해 보기 → 큰 숫자 → 꽉 차는 줄. 설명하는 줄만 밝히는 스포트라이트와 다음 칸을 톡톡 가리키는 도트 손가락), AI 뮤직맵
- 모든 소절(라스트 소절 포함)은 찍기 없이 줄 논리만으로 풀리도록 힌트(별 칸) 배치를 검증함

### 에셋
- 일러스트: GPT 이미지 도구(코덱스)로 그린 니케·블루 아카이브 풍 그림을 160×240 도트 스프라이트(머리부터 허리까지)로 줄임. 아랫몸은 코덱스가 원본 위쪽을 그대로 둔 채 이어 그렸고, 게임에서는 대화창 뒤로 이어져 잘린 선이 보이지 않음. 히로인마다 표정 6종(기본·웃음·노래·당황·눈 감음·웃으며 노래), 여섯 표정이 한 팔레트를 공유해 바꿔 끼워도 깜빡이지 않음. 그림이 풀리기 전 첫 프레임은 예전 코드 도트(`drawHeroine`)가 대신함
- 립싱크: 코덱스로 그린 입 모양 4종(살짝·에·아·오)과 크게 벌린 입을 음성 파일의 0.05초 단위 소리 크기·음색에 맞춰 바꿔 끼움(`VOICE_LIPS`). 웃는 얼굴로 말할 때는 웃는 눈을 유지한 채 입만 열고 닫음
- 터치 반응: 히로인 얼굴이나 몸을 누르면 살짝 커졌다 돌아오며 놀란 얼굴, 느낌표, 말풍선 대사와 음성(히로인마다 5줄, 계속 누를수록 짜증 섞임). 아래 대화창의 대사는 그대로
- 표정·몸짓 연출: 눈 깜빡임, 숨 쉬듯 위아래·좌우로 살짝 흔들림, 놀라거나 기쁘면 통통 튐, 싫거나 화나면 좌우로 도리도리, 실수하면 당황, 박자에 맞춰 들썩임
- 감정 아이콘: 코덱스(GPT 이미지)로 그린 도트 아이콘 8종(느낌표·물음표·화남 핏줄·하트·반짝이·땀방울·음표·말줄임). 대사 내용(?!, 앗, 치사해, 헤헤 …)과 호감도 변화·실수·클리어에 맞춰 머리 옆에 뜬다
- 소리: ElevenLabs 효과음 생성으로 만든 샘플 22종. 멜로디 악기 10종(칩튠·피아노·오르골·플루트·기타·신스 리드·바이올린·마림바·하프·트럼펫)은 음 하나를 녹음해 음높이를 재고 재생 속도로 각 음을 연주. 드럼 5종(킥·스네어·하이햇·박수·탬버린), 베이스, 코드(일렉 피아노), 패드, 효과음(오답·표시·완성 징글·관객 함성·글자 타이핑·버튼 클릭·곡 완성 팡파르·호감도 하트·행사 알림). 샘플을 못 읽는 환경에서는 예전 Web Audio 합성음이 대신함
- 배경 음악: ElevenLabs Music으로 만든 14곡(타이틀·학교·여름·겨울·데이트·두근·축제·엔딩 + 히로인 테마 6곡, 각 75초). 허브 곡은 계절 따라, 히로인을 만나면 그 히로인 테마로 바뀜. 끝나기 전에 처음부터 다시 겹쳐 틀어 이어지게 하고, 퍼즐·전곡 연주 중에는 멈추고, 목소리가 나오면 줄어든다
- 음성: ElevenLabs 보이스 디자인으로 만든 히로인 목소리 6개와 주인공 목소리 1개(eleven_v3). 플레이어 이름이 들어가는 대사는 읽지 않음. 목소리가 없는 줄은 글자 타이핑 소리가 난다. 파일 이름은 `<히로인>_<FNV-1a(히로인|대사)>.mp3`라서 대사를 고치면 그 줄만 다시 만들면 된다

### AI 뮤직맵
자유 연주 → AI 뮤직맵 → 노래 검색에서 노래 제목을 적으면, 코덱스가 웹에서 곡을 찾아(템포·코드·후렴 멜로디) 5소절 맵과 보컬·악기·대사를 만든다. 가사는 넣지 않는다.

```
node starlight-melody/music-map-server.js
```
- Node 18 이상과 로그인된 Codex CLI가 필요하다(코덱스 구독 사용량에서 나감). 서버는 `127.0.0.1:8131`에서만 듣는다
- 서버가 맵을 받으면 소절마다 줄 논리만으로 풀리는지 직접 풀어 보고, 가장 많은 칸을 풀리게 하는 칸부터 별 칸으로 채워 넣는다
- 만든 곡은 브라우저에 최대 12곡 저장된다
