# etc
Claude Code 클라우드 세션용 저장소

## 🎹 피아노 브릭스 (Piano Bricks)

원곡 멜로디는 지키고 방해 음 블럭만 깨는 **스테이지형 피아노 벽돌깨기** 게임입니다.
HTML5 파일 하나([`piano-bricks/index.html`](piano-bricks/index.html))에 화면·스타일·코드가 모두 들어 있어, 빌드나 서버 없이 이 파일만 브라우저로 열면 바로 실행됩니다.
(파일 하나만 복사해 옮겨도 돼요. 인터넷이 없으면 제목 글꼴만 기본 글꼴로 바뀝니다.)
**이 PC에서 웹 주소로 플레이:** [`piano-bricks/codex-bridge.cmd`](piano-bricks/codex-bridge.cmd)를 두 번 누르면 **http://localhost:8788** 에서 게임이 열리고 Codex 노래 찾기도 함께 켜집니다 (Node.js 필요, 창을 닫으면 꺼짐).
(GitHub Pages를 켜면 `/piano-bricks/` 주소로 휴대폰에서도 플레이할 수 있어요.)

### 두 가지 모드
- **스토리 모드 「두근두근 뮤직 세션 — 별의 석판」**: 80년대 애니 화풍의 우주 전쟁 로맨스 5장. 컷씬(배경·캐릭터·음성 대사·음악) 사이사이에 연주 스테이지가 들어가요. 설정과 줄거리는 [스토리-설정.md](piano-bricks/스토리-설정.md).
  - 캐릭터 6명·배경 11장은 Codex 이미지 도구(GPT 이미지)로, 대사 76줄·효과음·장면 음악은 ElevenLabs로 만들었어요.
  - 컷씬은 화면을 누르면 다음으로, 「자동」은 음성이 끝나면 넘어가고, 「건너뛰기」는 다음 연주까지 건너뛰어요. 연주를 깨면 「스토리 계속 ▶」.
  - 스토리 곡 「석판의 노래」는 이 게임을 위해 새로 작곡한 곡이에요 (연주 모드에서도 플레이 가능).
- **연주 모드**: 곡을 골라 스테이지를 플레이 (아래 설명).

### 화면
- 맨 위 한 줄: 나가기 · 곡 제목과 점수 · 남은 방해 블럭(받을 별 미리보기) · 남은 발사 수(원) · 소리 · 다시 하기, 그 아래 초록 선은 방해 블럭을 지운 비율
- 가운데(화면의 약 70%): 왼쪽 피아노 건반(최소 2옥타브, 24건반)과 그 바로 옆의 **재생 라인**, 나머지 전체가 음 블럭이 놓인 보드(피아노 롤, 반 박자 단위 16칸 = 8박), 위쪽 눈금에 마디 번호
- 아래 청록색 영역(화면의 약 20%) 가운데쯤에 **발판**(하얀 건반 모양)이 있고, 발판 위의 공을 조준해 발사합니다. (발판 아래에 손가락을 둬도 발판이 가려지지 않게 위로 올려 둠)
- 곡 선택 화면 위쪽의 **악기** 줄에서 멜로디 악기 10종 중 하나를 고릅니다. 플레이 중에도 위쪽 바의 **♪ 버튼**으로 바꿀 수 있어요 (창이 열려 있는 동안 조준·발사는 잠시 멈춤).
- 왼쪽 건반은 Codex 이미지 도구로 만든 **실사 건반**이에요. 음이 울리면 건반이 **눌린 모습**으로 바뀌어요 (맞는 음은 금색, 틀린 음은 빨간빛).

### 규칙
| 블럭 | 의미 | 공에 맞으면 |
|---|---|---|
| ⬜ 흰 블럭 | 원곡 멜로디 (흰 건반 음) | 안 깨짐, 공이 튕김 |
| ⬛ 검은 블럭 (반투명·점선) | 원곡 멜로디 (검은 건반 음) | 안 깨짐, 공이 **그냥 통과** (멜로디가 빽빽한 곡에서 길이 막히지 않게) |
| 🟦🟩🟥🟨🟪 컬러 블럭 | 방해 음 | 적힌 **숫자만큼** 맞히면 깨짐 |
| ⊕ 공 추가 블럭 | 방해 음 + 아이템 | 한 번에 깨지고 공이 바로 하나 더 나옴, 다음 발사부터 공 +1 (최대 5개) |
| ⚡ 속도 UP 블럭 | 방해 음 + 아이템 | 한 번에 깨지고 이번 턴 동안 공이 빨라짐 |
| ↔ 발판 UP 블럭 | 방해 음 + 아이템 | 한 번에 깨지고 아이템이 **천천히 떨어짐** → 발판으로 받아야 발판이 넓어짐 |

- 한 스테이지 = 노래의 한 소절(8박), 한 스테이지당 **20번 발사**
- 공이 어떤 블럭에 부딪혀도 **곡의 멜로디가 한 음씩 이어서** 울립니다. 블럭을 칠수록 노래가 연주돼요.
- 배경에는 지금 곡의 코드로 된 잔잔한 반주(패드·베이스·뮤직박스)와 바람 소리가 작게 반복됩니다. (곡을 연주할 때는 반주가 작아져요.)
- 블럭을 칠 때의 멜로디와 곡 연주는 고른 **멜로디 악기**로 울립니다.
- 공이 날아가는 동안 발판을 좌우로 움직여 공을 받아냅니다. 놓친 공은 사라져요.
- 공이 날아가는 중에도 보드를 눌러 조준하면 **추가 발사**할 수 있어요. 발사 횟수를 1번 쓰고, 그 턴의 8초가 다시 시작돼요.
- 날아가는 공에는 빛 꼬리가 남고, 블럭이 깨지면 블럭 조각이 흩어지며 화면이 살짝 흔들려요.
- 공이 흰 블럭에 맞거나 검은 블럭을 지나가면 빛나는 음표(♪♫)가 나타나 위로 올라가다 사라져요 (흰 블럭은 금빛, 검은 블럭은 보랏빛).
- 보드의 블럭(흰·검은 멜로디 블럭, 6색 방해 블럭)은 Codex 이미지 도구로 만든 광택 타일 그림이에요. 긴 음은 모서리를 지킨 채 늘려 그려요.
- 결과 화면(PERFECT · STAGE CLEAR · 완곡)이 뜨면 축하 효과음과 함께 칭찬 목소리가 나오고, 색종이가 터져 흩날려요. GAME OVER에는 응원 목소리만 나와요.
- 쏜 공을 모두 놓치거나 **8초**가 지나면 그 발사 턴이 끝나요. 한 턴이 길어질수록 공이 점점 빨라집니다.
- 발사할 때마다 보드가 재생 라인 쪽으로 흘러갑니다.
- 20번이 끝나면(또는 방해 블럭을 다 깨면) 보드가 재생 라인을 지나가며 연주됩니다. 남은 방해 블럭은 **틀린 음**으로 연주돼요.
- 남은 방해 블럭 **0개 ★★★ · 1~5개 ★★ · 6~10개 ★ · 11개 이상 GAME OVER**
- 한 곡의 모든 스테이지를 클리어하면 **전곡 듣기**로 곡 전체를 연주합니다 (남겨 둔 방해 블럭도 함께 연주됨).

### 수록곡 (모두 저작권 만료 곡)
작은 별(3스테이지) · 비행기(3) · 징글벨(5) · 환희의 송가(5) · 석판의 노래(4, 스토리 모드용 창작곡)

**PC 전용 곡:** `piano-bricks/local-songs/*.json`에 넣은 곡은 http://localhost:8788 로 열었을 때 곡 목록에 「PC 전용」으로 함께 나와요. 저작권이 살아 있는 곡을 넣는 곳이라 GitHub에는 올라가지 않습니다 (`.gitignore`). 파일 형식은 Codex 받아 적기 결과(`bpm`, `notes`, `chords`)에 `id`·`title`·`en`·`level`·`stages`를 더한 것.

### 새 곡 만들기 (곡 선택 → `+ 새 곡 만들기`)
- **노래 찾기 (Codex)**: 아무 노래나 제목·가수·기억나는 가사로 찾으면 Codex가 웹에서 곡을 찾아 후보(최대 6곡)를 보여 주고,
  고른 곡의 대표 구간 멜로디·코드·템포를 웹에서 확인해 받아 적어 맵을 만듭니다.
  - 이 PC의 Codex 로그인(ChatGPT/Codex 구독)을 쓰므로, **이 PC에서 [`piano-bricks/codex-bridge.cmd`](piano-bricks/codex-bridge.cmd)를 실행해 둔 채로** 게임을 열어야 해요 (Node.js 18 이상 필요).
  - 걸리는 시간: 찾기 약 15~20초, 받아 적기 약 1~4분. 같은 곡은 하루 동안 저장된 답을 다시 씁니다.
  - 브리지는 `127.0.0.1:8788`에서만 열리고, 노래 찾기·받아 적기 두 가지 일만 합니다 (Codex는 읽기 전용 + 웹 검색, 빈 임시 폴더에서 실행).
  - 브리지가 꺼져 있고 claude.ai 아티팩트로 열었다면 예전처럼 Claude가 제목으로 맵을 만듭니다.
- **음악 파일로**
  - **MIDI(.mid)**: 악보를 그대로 읽어 멜로디 트랙(이름이 melody/vocal이거나 가장 높은 파트)과 코드를 뽑습니다. 가장 정확해요.
  - **MP3·WAV·M4A 등**: 브라우저 안에서 템포·박자·멜로디 음높이·조성·코드를 분석해 만듭니다. 시작 시간을 정할 수 있고, 거기서부터 80초를 분석해요.
    반주가 많은 곡은 멜로디 대신 다른 악기 소리를 잡을 수 있어요. 깨끗한 멜로디(허밍, 피아노 연주)일수록 정확합니다.
- 난이도(쉬움/보통/어려움)와 길이(최대 4·6·8스테이지)를 고를 수 있고, 같은 구절은 한 스테이지로 합쳐집니다.
- 만든 곡은 곡 목록의 **내가 만든 곡**에 저장되고(이 브라우저), 두 번 눌러 삭제할 수 있어요.

### 소리 (ElevenLabs)
모든 악기 소리와 효과음은 [ElevenLabs](https://elevenlabs.io) 효과음 API로 만든 녹음이며, `index.html` 맨 끝의 `PB.SOUND_DATA`에 MP3(모노)로 들어 있습니다.
- **멜로디 악기 11종**: 피아노 · 그랜드 피아노(맑고 밝은 콘서트 그랜드) · 뮤직박스 · 하프 · 마림바 · 기타 · 바이올린 · 플루트 · 첼레스타 · 전자피아노 · 비브라폰
- **반주·기타**: 패드, 베이스, 틀린 음(어긋난 업라이트 피아노), 블럭 깨짐, 발사, 발판 노크, 공 놓침, 바람(끊김 없는 반복), 축하음(큰·작은)
- **목소리**: ElevenLabs 음성 합성(목소리 「AF-Rara-JY」)으로 만든 결과 화면 칭찬·응원 문장 5개
- 악기마다 음높이가 다른 녹음 3~7개를 받아 실제 음높이를 분석해 두고, 가장 가까운 녹음을 재생 속도로 맞춰 원하는 음을 냅니다.
- 녹음을 불러오기 전 잠깐과 불러오기에 실패했을 때는 예전 합성음이 대신 울립니다.

### 조작
- 조작 안내는 맨 처음 한 번만 보드에 떠요. 다시 보려면 보드 오른쪽 위의 **?** 버튼을 누르세요 (안내가 떠 있을 때의 터치는 안내만 닫고, 발사는 다음 터치부터).
- 터치/마우스: 위쪽을 눌러 조준 → 손을 떼면 발사, 공이 날아가는 동안 좌우로 밀어 발판 이동
- 조준 중 발판 줄을 누르고 밀면 발사 위치(발판)를 옮길 수 있어요.
- 키보드: ← → 조준 / 발판 이동, Space/Enter 발사

### 밸런스
방해 블럭 체력(숫자)은 `index.html` 안 core 부분의 `tuning` 값으로 정해지며, 발판으로 공을 받는 확률을 65%·80%·90%로 둔 가상 플레이어 시뮬레이션으로 맞췄습니다.
첫 곡은 누구나 ★★★, 뒤로 갈수록 어려워져 마지막 스테이지는 서툴면 GAME OVER가 나옵니다. 한 스테이지는 약 1~4분입니다.

### 코드 구조
레벨 데이터를 게임 로직과 분리한 [jakesgordon/javascript-breakout](https://github.com/jakesgordon/javascript-breakout)의 구조를 참고했습니다.
`index.html` 하나에 `<style>` 하나와 `<script>` 둘(게임 코드, 블럭 그림 `PB.BLOCK_ART`·건반 그림 `PB.KEY_ART`·소리 데이터 `PB.SOUND_DATA`)이 들어 있고, 게임 코드는 아래 순서의 부분으로 나뉩니다.
(각 부분은 `/* ===== js/이름.js ===== */` 주석으로 시작해요.)

| 부분 | 내용 |
|---|---|
| `songs` | 곡·스테이지 데이터 (멜로디, 코드, 전곡 순서) — 새 곡은 여기에 추가 |
| `core` | 화면 배치 상수, 스테이지 생성(방해 블럭 배치·난이도), 공 물리 |
| `maker` | 맵 만들기: 멜로디 → 스테이지, Claude 답 해석, MIDI 파서, 음악 분석(FFT·템포·음높이·조성·코드) |
| `audio` | 소리 재생: 녹음 샘플(10종 멜로디 악기, 반주, 효과음, 바람)을 음높이에 맞춰 재생, 불러오기 전에는 합성음 |
| `game` | 게임 진행, 그리기, 입력, 결과/메뉴 화면, 진행도 저장(localStorage) |
| `create` | 새 곡 만들기 화면 (노래 찾기 → Codex 브리지 / Claude, 파일 → MIDI/음악 분석) |

게임 밖 도우미: [`codex-bridge.mjs`](piano-bricks/codex-bridge.mjs) (Codex로 노래 찾기·받아 적기, 로컬 전용) · [`codex-bridge.cmd`](piano-bricks/codex-bridge.cmd) (두 번 눌러 실행)
