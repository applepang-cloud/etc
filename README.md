## 별빛 멜로디 (`starlight-melody/`)
음표 퍼즐(노노그램)을 풀어 여주인공 리아의 노래를 한 소절씩 완성하는 도트 서브컬처 퍼즐 게임 프로토타입.

- 단일 HTML 파일 (`starlight-melody/index.html`), 외부 이미지나 사운드 파일 없음
- 퍼즐판 = 8스텝 시퀀서: 맞게 칠한 칸이 그대로 반복 재생됨 (Web Audio 칩튠)
- 3곡 × 5소절: 별빛 멜로디(튜토리얼 포함), 비 갠 오후(느린 발라드), 점프! 스테이지(빠른 앙코르, 상급)
- 모든 소절은 찍기 없이 줄 논리만으로 풀리도록 힌트(별 칸) 배치를 검증함
- 여주인공 도트 일러스트는 코드로 생성한 임시 그림 (`drawHeroine`), 나중에 실제 일러스트로 교체 예정
