# 방치형 코인 키우기

시드머니 100만 원으로 시작해 코인으로 자산을 불리는 방치형(아이들) 게임입니다. 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행

- `index.html`을 더블클릭해서 엽니다.
- 한 파일로 묶고 싶으면 `node build.mjs dist/coin-idle.html`을 실행합니다.
- 진행 상황은 브라우저(localStorage)에 10초마다 자동 저장됩니다. 창을 닫아도 최대 8시간까지 시장·사업·매니저가 계속 돌아가고, 다시 열면 "다녀오셨어요?" 보고서가 뜹니다.

## 시간

- 실제 1초 = 게임 12분(1틱), 실제 2분 = 게임 하루입니다.
- 캔들은 1시간(5틱) · 4시간(20틱) · 1일(120틱) 단위입니다.

## 코인 (상세)

- 코인 14종: 실제 코인 10종(BTC, ETH, XRP, SOL, DOGE, ADA, AVAX, LINK, SHIB, PEPE)과 가상 코인 4종(AIX, 김치코인, 도토리, 문샷). 시세는 모두 게임용 가상 데이터입니다.
- 시세 엔진: 시장 국면(횡보·상승·하락·광기·패닉), BTC와의 상관관계, 코인별 변동성, 장기 추세선으로의 평균회귀, 뉴스 충격.
- 거래: 시장가 매수/매도(유동성에 따른 슬리피지와 수수료), 지정가 주문, 예약매도(익절/손절), 선물(롱/숏, 1~25배, 청산가, 펀딩비), 스테이킹(일 복리).
- 화면: 캔들 차트(이동평균 · 볼린저 밴드 · 거래량 · RSI, 내 매매 표시), 호가창(업비트식 호가 단위), 체결 내역, 김치 프리미엄 · 해외 시세, 공포·탐욕 지수.
- 가상 잡코인은 러그풀(폭락)과 리브랜딩(부활)이 일어납니다.

## 매니저

- 지원자를 고용하고(계약금 = 일급 2일치) 담당 코인과 역할을 지정합니다.
  - 자율 매매: 맡긴 자금으로 직접 사고팝니다.
  - 매수 전담: 예산을 나눠 좋은 타이밍에 사서 내 지갑에 넣습니다.
  - 매도 전담: 내 지갑의 코인을 익절/손절 기준에 맞춰 나눠 팝니다.
- 전략 5종(단타, 추세 추종, 저점 매수, 장기 존버, 뉴스 트레이더)과 실력(별 1~5개). 실력이 높을수록 앞으로 반영될 재료를 더 잘 읽습니다. 거래할수록 레벨업합니다.
- 급여는 하루마다 현금에서 나가고, 못 받으면 퇴사합니다.

## 뉴스

- 국내 · 해외 · 유튜브 뉴스가 시세를 움직입니다. 루머는 나중에 정정 보도가 나오고, "재료 소멸"로 되돌려지는 호재도 있습니다.
- 유튜브 영상은 채널 성향(선동형 · 공포형 · 분석형 · 차분한 경제 채널 등)에 따라 신뢰도가 다르고, 낚시 영상은 반짝 오른 뒤 빠집니다.
- 경제 캘린더: 美 FOMC, 한국은행 금통위, 비트코인 반감기.
- 실제 뉴스가 궁금하면 뉴스 탭 · 코인 상세의 링크로 구글 뉴스(국내/해외)와 유튜브 검색을 새 탭에서 엽니다.

## 주식 · 부동산 · 사업 (단순)

- 주식: 국내/해외 가상 종목 11개, 지수와 기준금리 영향, 7일마다 배당.
- 부동산: 고시원부터 랜드마크 타워까지 9종. 부동산 지수와 금리에 따라 시세가 움직이고 매일 임대료가 들어옵니다.
- 사업: 붕어빵 노점부터 코인 거래소까지 8종을 레벨업. Lv.10/25/50/100/200마다 수익이 배로 뜁니다.
- 스타트업 지분 투자: 단계별 성공 확률과 회수 배수가 다르며, 결과는 며칠 뒤 나옵니다.

## 라이프

- 자동차 11종: 매력이 오르고, 매일 유지비가 나가며, 시간이 지나면 감가됩니다.
- 연애: 데이팅 앱부터 요트 파티까지 만남 → 고백 → 데이트(성격별 취향) → 프로포즈 → 결혼. 호감도가 바닥나면 이별합니다.
- 인맥 10종: 여자친구 소개, 네트워킹 행사, 게임 진행으로 해금되고 친밀도에 따라 혜택이 커집니다(뉴스 귀띔, 수수료 할인, 취득세 감면, 스타트업 성공률, 절세, 낚시 영상 판별 등).
- 쇼핑 · 소비: 명품, 요트, 전용기, 여행, 기부 등으로 행복 · 매력 · 명성을 올립니다. 행복이 높을수록 사업 · 임대 · 채굴 수입에 보너스가 붙습니다.

## 사운드

효과음과 배경음악 모두 Web Audio로 실시간 합성합니다(외부 음원 파일 없음). 배경음악은 공포·탐욕 지수에 따라 분위기가 바뀝니다. 브라우저 정책상 첫 클릭 이후에 소리가 납니다.

## 파일 구조

```
index.html      화면 골격
css/style.css   스타일 (라이트/다크, 한국식·해외식 상승 색상)
js/util.js      포맷(억·조 단위, 호가 단위), 난수, 지표
js/data.js      코인·뉴스·매니저·채굴·주식·부동산·사업·라이프 데이터
js/audio.js     효과음 · 배경음악
js/state.js     상태 생성 · 저장 · 불러오기
js/market.js    코인 시세 엔진
js/news.js      뉴스 · 유튜브 · 일정 이벤트 · 귀띔
js/trading.js   시장가 · 지정가 · 예약매도 · 선물 · 스테이킹
js/managers.js  매니저 AI
js/assets.js    채굴 · 주식 · 부동산 · 사업 · 스타트업 · 총자산
js/life.js      자동차 · 연애 · 인맥 · 소비
js/engine.js    틱 진행 순서 · 업적
js/chart.js     캔버스 차트
js/ui.js        화면 갱신
js/main.js      게임 루프 · 버튼 동작 · 오프라인 진행
build.mjs       한 파일로 묶기
```
