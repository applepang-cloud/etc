# 방치형 공주 키우기

프린세스 메이커식 육성을 **방치형(idle)** 으로 바꾼 브라우저 게임입니다.
열 살 공주를 열여덟 살 성인식까지 8년 동안 키웁니다. 일정만 짜 두면 공주가 알아서 하루하루를 보내고, 창을 닫아도 시간이 흐릅니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 시작됩니다.

```bash
cd princess-idle
npm start          # 로컬 서버로 열기 (npx serve)
npm test           # 엔진 테스트 (node --test)
```

## 어떻게 바뀌었나

| 원작의 육성 | 방치형 공주 키우기 |
| --- | --- |
| 매달 직접 일정을 고르고 넘긴다 | 한 달(상순·중순·하순) 일정을 짜 두면 **매달 반복**되고, 하루가 1.5초씩 저절로 흐른다 |
| 스트레스가 쌓이면 직접 휴가를 보낸다 | **자동 휴식**: 스트레스가 정해 둔 값을 넘으면 알아서 쉬고 회복되면 일정으로 돌아간다 |
| 같은 수업을 반복하면 실력이 붙는다 | 활동마다 **숙련도(Lv.0~10)** 가 쌓여 성장량과 일당이 오른다 |
| 물건 구입 | 골드로 **방 꾸미기**: 능력치 성장·수입·스트레스 배율을 올린다. **자동 구매**도 켤 수 있다 |
| 엔딩 후 처음부터 다시 | 성인식 엔딩에 따라 **왕관 별**을 받고, **유산**으로 다음 세대를 영구 강화한다 (환생) |
| — | 창을 닫아도 진행되는 **오프라인 진행** (기본 1시간, 유산으로 연장) |

## 시스템

- **능력치 10종** — 몸(체력·근력·무예), 머리(지력·마력), 품격(기품·매력·감성), 마음(인성·영성). 최대 999.
- **시작 보너스** — 새 공주가 들어올 때마다 포인트 3개를 지력·체력·매력·인성·감성·영성에 직접 나눠 준다 (1포인트 = +10). 다 나눠야 시작할 수 있다.
- **성장 포인트** — 10일마다 1개, 숙련도 레벨업 +1, 생일 +3씩 쌓인다. 공주 화면에서 지력·체력·매력·인성·감성·영성 중 골라 누르면 1포인트에 +2.
- **자동 선택** — 켜져 있는 동안 쌓인 포인트를 알아서 쓴다(골고루 또는 정한 능력치). **보석** 5개로 10분, 20개로 1시간, 또는 **광고 보고 1분**. 자동 시간은 게임이 흐를 때만 줄어든다.
- **보석** — 처음 10개, 생일 +2, 수확제 우승 +1, 보물 상자 +1, 용 처치 +20, 엔딩(S 30·A 15·B 8·C 3). 세대를 넘어 남는다.
- **광고 자리** — 지금은 5초짜리 자리 표시만 있다. 실제 보상형 광고는 `js/ui.js`의 `adModal`에 광고 SDK를 연결하면 된다.
- **활동 24종** — 수업 8, 아르바이트 11, 무사수행 3, 휴식 2. 나이·능력치 조건으로 해금된다.
- **무사수행** — 매일 전투력과 위험도로 승패를 판정한다. 용의 산맥에서는 드물게 붉은 용이 깨어난다.
- **수확제** — 매년 10월 15일 무술 대회·미인 대회·예술제·마법 경연이 자동으로 열린다.
- **무작위 사건** — 동전 줍기, 감기, 왕자와의 만남 등 21가지.
- **엔딩 25종** — 여왕·성녀·대마도사·용사·대장군(S)부터 평범한 아가씨(C)까지. 위에서부터 먼저 만족한 엔딩이 된다.
- **저장** — 브라우저 `localStorage`에 자동 저장되며, 설정에서 저장 데이터를 복사해 다른 기기로 옮길 수 있다.

## 파일

```
princess-idle/
├── index.html
├── css/style.css
├── js/data.js       # 능력치·활동·상점·유산·엔딩·사건 데이터 (밸런스는 여기서)
├── js/engine.js     # DOM 없는 게임 엔진 (하루 진행, 엔딩, 저장)
├── js/portrait.js   # 나이·기분·계절에 따라 바뀌는 공주 SVG
├── js/ui.js         # 화면, 실시간 진행, 오프라인 진행
└── test/engine.test.js
```

엔진은 시드 난수를 저장하므로 같은 저장 데이터에서는 항상 같은 미래가 펼쳐집니다.
